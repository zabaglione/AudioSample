# AudioSample

A Unity sample project that demonstrates audio playback, microphone input and basic visualization techniques.

This project uses **Unity 2021.3.28f1** and includes the [MusicEngine](Assets/MusicEngine/README.md) library for beat synchronization. Additional tools such as DOTween and TextMesh Pro are already included via packages or plugins.

## Features

- **BeatChecker** scene: sync objects to the tempo of a playing track.
- **MicInput** scene: visualize microphone volume using TextMesh Pro.
- **LineVisualizer** scene: render audio data with a line renderer.
- **RainDrop** scene: spawn objects that play randomized sound effects.
- **SineWave** scene: generate tones from code.
- **SpectrumAnalyzer** scene: 3D spectrum visualization with peak detection.

Audio assets are located under `Assets/Audio`.

## Getting Started

1. Clone this repository.
2. Open the project in Unity **2021.3.28f1** or newer.
3. Open any scene from `Assets/Scenes` and press **Play**.
4. Connect a microphone for mic-based samples.

## 日本語

Unity における音声再生やマイク入力、そして基本的な可視化手法を解説するサンプルプロジェクトです。

このプロジェクトは **Unity 2021.3.28f1** を利用し、ビート同期のために [MusicEngine](Assets/MusicEngine/README.md) ライブラリを含んでいます。DOTween や TextMesh Pro などのツールもパッケージやプラグインとして組み込まれています。

### 主なシーン

- **BeatChecker** シーン：再生中のトラックのテンポにオブジェクトを同期します。
- **MicInput** シーン：TextMesh Pro を使用してマイク入力の音量を可視化します。
- **LineVisualizer** シーン：Line Renderer を用いてオーディオデータを描画します。
- **RainDrop** シーン：ランダムな効果音を再生するオブジェクトを生成します。
- **SineWave** シーン：コードから音声を生成します。
- **SpectrumAnalyzer** シーン：ピーク検出を行う 3D スペクトラム表示です。

オーディオ素材は `Assets/Audio` に配置されています。

### はじめに

1. このリポジトリをクローンします。
2. Unity **2021.3.28f1** 以降でプロジェクトを開きます。
3. `Assets/Scenes` フォルダから任意のシーンを開き **Play** を押します。
4. マイクを接続すると、マイク入力を使ったサンプルを試せます。
